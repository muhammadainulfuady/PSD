## 📌 Daftar Instruksi & Pengerjaan Tugas

### 1. Penanganan Missing Value (Imputasi Polinomial)

- **Perubahan Metode:** Pengisian data yang hilang (_missing value_) yang sebelumnya menggunakan **imputasi linier** kini diganti sepenuhnya menggunakan **imputasi polinomial**.

### 2. Ekstraksi Fitur

- **Penyesuaian Input Data:** Proses ekstraksi fitur wajib menggunakan dataset hasil dari imputasi polinomial (bukan hasil imputasi linier).

### 3. Deteksi Outlier (KNIME)

- **Pengolahan Kembali:** Lakukan proses deteksi data pencilan (_outlier detection_) ulang pada software **KNIME** menggunakan algoritma **K-Means**. MENUNGGU DATA DARI TEMAN TEMAN BISA DIKERJAKAN BAGIAN 4

### 4. Pemetaan & Klasifikasi Lahan (Sawah & Pemukiman)

- **Pengambilan Data (GeoJSON Crawling):** Tentukan koordinat area untuk **50 titik sawah** dan **50 titik pemukiman**.
- **Pengunduhan Citra:** Unduh data citra satelit **Sentinel-2A** berdasarkan area GeoJSON tersebut hingga menghasilkan keluaran berupa **file TIF**.
- **Klasifikasi Lahan:** Lakukan klasifikasi untuk memvalidasi dan membedakan area mana yang termasuk sawah dan pemukiman.
